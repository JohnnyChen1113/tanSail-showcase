# Internationalization

TanSail ships English and Simplified Chinese as first-class routes:

- `/en`
- `/zh`

The root route redirects to `/en`. `src/i18n.ts` owns the locale union, typed dictionaries,
fallback behavior, route helpers, localized accessibility labels, and appearance-control copy.
Both dictionaries satisfy the same `Dictionary` type at compile time.

## Add or change copy

Edit the matching object in `src/i18n.ts`. The compiler reports missing fields immediately. Keep
product facts aligned across languages, but translate for natural reading rather than preserving
English sentence structure.

## Add a locale

1. Add the locale to `locales` and extend `Locale`-dependent route types.
2. Add a complete typed dictionary.
3. Add a file route and localized head configuration.
4. Extend the language switcher behavior, sitemap entries, canonical links, and `hreflang` output.
5. Define suitable type fallbacks and display metrics in `src/styles.css`.
6. Add unit and Playwright coverage for routing, `<html lang>`, metadata, overflow, and mobile
   navigation.

Invalid locale input falls back to English; public links always use an explicit locale path.
