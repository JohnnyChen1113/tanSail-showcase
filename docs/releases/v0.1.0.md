# TanSail v0.1.0

TanSail's first public release is a design-first TanStack Start starter for building polished sites
on Cloudflare Workers without a database, authentication provider, payment service, or required
secret.

## Highlights

- Three complete visual directions: Harbor, Horizon, and Nightwatch.
- Typed site configuration, semantic design tokens, accessible navigation, and central SEO.
- Reusable hero, proof, feature, use-case, testimonial, pricing, FAQ, stats, and CTA blocks.
- Six page recipes for SaaS, AI, open-source, indie, knowledge, and consulting sites.
- Optional MDX docs and blog content with supporting marketing-page recipes.
- A guarded one-prompt workflow that turns a structured brief into a checked generated preview.
- Cloudflare Worker builds with static prerendering for public routes.

## Validation

- Formatting, lint, and type checks pass.
- 23 unit tests pass across seven test files.
- 16 portable desktop and mobile browser tests pass in CI; six platform-sensitive visual preset
  snapshots remain available as a local design check.
- The production build prerenders 22 public pages.

## Migration notes

This is the first TanSail release, so there is no previous TanSail version to migrate from. Projects
based directly on TanStarter should start with a fresh TanSail checkout or port configuration and
content selectively. TanSail intentionally removes the baseline authentication, database, ORM,
PostgreSQL, and demo routes; those capabilities are not migrated automatically.

Requirements are Node.js 24 or newer, pnpm 11 or newer, and Vite+.

## Known limitations

- Authentication, database, billing, email, analytics, storage, and CMS integrations are not yet
  published as optional recipes.
- The repository ships reusable source and local previews; consumers provide their own production
  domain and Cloudflare account configuration.
