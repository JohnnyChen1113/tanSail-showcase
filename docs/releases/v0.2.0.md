# TanSail v0.2.0

TanSail v0.2.0 turns the starter into a design-governed, bilingual foundation with a clean-room
reference workflow and a much more deliberate product-facing UI.

## Highlights

- `DESIGN.md` is now an executable contract: lint it, diff it, export Tailwind CSS 4 tokens, and
  verify synchronization in CI.
- `/en/` and `/zh/` are first-class routes with typed dictionaries, language-aware typography,
  canonical URLs, `hreflang`, localized accessibility copy, and sitemap entries.
- The new Luminous Harbor homepage uses real product interface compositions and reserves glass for
  navigation and functional controls.
- The `$reference-to-tansail` skill translates URLs or screenshots into an auditable SITE-BRIEF
  and proposed design contract while rejecting copied code, assets, or exact reproduction.
- Harbor, Luminous, and Signal preserve stable geometry across appearance changes, preventing the
  layout collisions that could occur when presets changed composition.

## Migration notes

- The root route redirects to `/en/`; add or update locale-specific links when integrating custom
  pages.
- Homepage copy now lives in typed dictionaries in `src/i18n.ts`.
- Preset IDs remain `harbor`, `horizon`, and `nightwatch` for storage compatibility, while their
  user-facing labels are Harbor, Luminous, and Signal.
- Run `vp run design:export` after changing root `DESIGN.md`, and commit the generated CSS.

## Validation

The release gate includes design-contract synchronization, formatting, lint, type checking, unit
tests, portable Chromium behavior tests, production build, Cloudflare prerendering, and manual
desktop/mobile screenshot review. Platform-specific pixel baselines remain a local optional check.
