# Changelog

All notable TanSail changes are recorded here. The project follows semantic versioning, with the
understanding that pre-1.0 minor releases may contain documented breaking changes.

## Unreleased

No changes yet.

## 0.1.0 — 2026-07-28

### Added

- A secret-free React 19 and TanStack Start foundation for Cloudflare Workers.
- Typed site identity, navigation, metadata, sitemap, robots, and reusable site-shell components.
- Harbor, Horizon, and Nightwatch visual presets with light, dark, and system themes.
- A typed landing-block library, local block gallery, and six complete page recipes.
- Optional MDX documentation and blog modules plus changelog, legal, contact, structured-data, and
  share-image recipes.
- A guarded brief schema, generated preview, example fixtures, and the `$build-tansail-site` Codex
  skill.
- Unit, portable browser, build, dependency-review, and release automation, plus local screenshot
  baselines for visual review.

### Removed from the upstream baseline

- Bundled authentication, database, ORM, PostgreSQL, and demo application code.
- Required secrets and project-specific infrastructure from the default starter.
