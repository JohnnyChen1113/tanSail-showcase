# Content and internationalization

TanSail treats English and Simplified Chinese as equal public routes, not as a client-side translation patch. Each locale has an explicit URL, complete dictionary, correct `<html lang>`, independent metadata, and matching `hreflang` links.

Locales should communicate the same facts without preserving sentence structure. Keep product terminology natural in English and use appropriate line breaks and concise headings in Chinese. Avoid large `locale === "zh"` copy branches inside JSX; reserve those for small template UI labels.

<h2 id="locale-routes">Locale routes</h2>

Homepages use `/en/` and `/zh/`; documentation uses `/docs/en/` and `/docs/zh/`. The `Locale` union and `isLocale` validate dynamic params. Invalid docs locales return not found, and public links always use explicit locale paths.

A language switch preserves the article slug: `/docs/en/design-contract/` maps to `/docs/zh/design-contract/`. Links keep the route template and pass locale and slug through typed `params`.


Both locales share slug, order, and section. Every TOC ID corresponds to an explicit heading ID. Routes generate SEO-length titles and descriptions, with optional `seoTitle` and `seoDescription` overrides.

<h2 id="typography">Language typography</h2>

CJK display text uses system fallbacks, a smaller maximum size, more line height, and less negative tracking than Latin. Target roughly 28–36 Han characters or 60–72 Latin characters per body line. Inspect button wrapping, long English tokens, Chinese punctuation, code terms, and fallback fonts.

<h2 id="add-locale">Add a locale</h2>

1. Extend `locales` and all `Locale`-dependent types.
2. Add a complete dictionary instead of relying on English fallback.
3. Add homepage routes, documentation content, and language-switch mapping.
4. Update canonical, `hreflang`, sitemap, `<html lang>`, and metadata.
5. Define suitable font fallbacks and display metrics.
6. Add unit and Playwright coverage for routing, metadata, overflow, and mobile navigation.

Only then is the locale first-class.
