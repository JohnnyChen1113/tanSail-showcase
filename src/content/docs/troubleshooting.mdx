# Commands and troubleshooting

Use this page to diagnose common TanSail failures by symptom. Preserve the complete error output and fix the earliest root cause. Avoid changing dependencies, screenshot baselines, and product code at the same time.

<h2 id="toolchain">Toolchain problems</h2>

**`vp`, `vpr`, or `vpx` is missing:** install Vite+, confirm the binary is on PATH, then confirm Node ≥24 and pnpm ≥11. Package scripts such as `pnpm dev` remain available, but repository workflows assume Vite+ behavior.

**Dependency or lockfile mismatch:** do not delete the lockfile blindly. Run `vp install` and determine whether the cause is registry access, Node engines, or catalog resolution. Run the full gate after dependency changes.

<h2 id="routes-and-mdx">Routes and MDX</h2>

**A new route has no types:** run the dev server or build so the Router plugin updates `src/routeTree.gen.ts`. Do not edit it manually.

**A dynamic Link fails:** keep `to="/docs/$locale/$slug/"` and pass `params={{ locale, slug }}`. Do not interpolate the path.

**MDX fails to build:** check schema-valid metadata, closed JSX tags, lowercase kebab-case TOC IDs, and balanced code fences. Locale pairs share slug and order, and slugs are unique within a locale.

<h2 id="design-and-browser">Design and browser tests</h2>

**`design:check` reports a stale export:** if the contract change is intentional, run `vp run design:export`; if only generated CSS changed, move the decision to the contract source.

**Playwright cannot find a browser:** run `pnpm exec playwright install chromium` or use `TANSAIL_BROWSER_CHANNEL=chrome`. If a port is busy, identify the existing server before stopping any process.

**Screenshot mismatch:** separate font/OS noise from a real layout regression. Run `pnpm test:visual:update` only after reviewing the new result.

<h2 id="deployment">Deployment problems</h2>

Authenticate with `pnpm wrangler login`, or verify CI token scope. If the Worker builds but the URL shows unexpected content, check Worker name, environment, production origin, and cache. If canonical still uses example.com, update `siteConfig.metadata.siteUrl` and rebuild. A docs 404 usually means a missing locale import, wrong slug param, or sitemap path mismatch.

For unresolved failures, record the command, complete error, Node/pnpm/Vite+ versions, operating system, browser channel, and minimal reproduction route.
