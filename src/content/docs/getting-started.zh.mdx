# 快速开始

默认 TanSail 可以在没有账号、数据库、密钥和外部服务的情况下启动。本页会先得到一个可运行基线，再帮助你选择手动配置、自然语言 brief 或参考网站三种路径。

先确认版本：

```bash
node --version
pnpm --version
vp --version
```

<h2 id="install-and-run">安装并运行</h2>

```bash
pnpm install
pnpm dev
```

开发服务器默认位于 `http://localhost:3000`。访问 `/en/` 与 `/zh/` 检查双语首页，访问 `/docs/zh/` 检查文档，访问 `/recipes/` 比较完整叙事，访问 `/gallery/` 单独检查区块。首次启动不需要创建 `.env`。

如果你使用仓库约定的 Vite+ 简写，同一条启动命令也可以写成：

```bash
vpr dev
```

<h2 id="first-change">第一次修改</h2>

先从内容边界开始，不要直接改 Hero JSX：

1. 在 `src/config/site.ts` 修改站点名、生产 origin、导航、动作和页脚。
2. 在 `src/i18n.ts` 同步修改英文和中文文案。
3. 在 `src/config/presets.ts` 设置默认 preset，或保留访客可切换行为。
4. 刷新 `/en/`、`/zh/`，确认标题、按钮和页脚没有语言错位。

站点 metadata schema 会拒绝短于 40 字符的 title、短于 140 字符的 description、带尾部 `/` 的 origin 和无效链接。验证失败时应修正配置，而不是绕过 schema。

<h2 id="verify">验证结果</h2>

完成一个小改动后先运行快速门禁：

```bash
vp check
vp test run
vp build
```

`vp check` 覆盖格式、lint 和类型；测试检查 schema、路由和内容不变量；构建会生成 Cloudflare Worker 并预渲染公开页面。若只想确认应用是否能启动，仍应在提交或部署前补跑完整门禁。
