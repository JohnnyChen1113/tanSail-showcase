# Clean-room references

A reference is design research, not a source-code, copy, or asset library. TanSail separates observations from implementation in a structured intake so every reference-derived decision remains auditable.

<h2 id="boundary">Clean-room boundary</h2>

Every intake sets `copySourceCode: false`, `copyAssets: false`, and `exactReproduction: false`. Do not transfer logos, brand names, customer marks, paid illustrations, product screenshots, long-form copy, or proprietary bundles. Do not promise pixel-perfect reproduction.

General principles are valid research: three-column documentation navigation, readable article measure, search placement, heading hierarchy, and mobile directory behavior. The final palette, type pairing, copy, components, and interaction details belong to the target project.

<h2 id="observations">Record observations</h2>

Record hierarchy, typography, color/material, interaction, and explicit elements to avoid. Use measurable statements such as “the desktop article is approximately 800px wide and the right TOC disappears below a wide breakpoint,” not vague requests to make a page feel premium.

<h2 id="transformations">Original transformations</h2>

Every intake needs at least three visible transformations: a different grid, original palette/type pairing, original product imagery, a different section sequence, or a different interaction detail.

<h2 id="commands">Generate guarded documents</h2>

```bash
vp run reference:brief -- --input examples/reference/reference-brief.json
vp run reference:brief -- --input examples/reference/reference-brief.json --apply
```

The first command validates and previews. `--apply` writes fixed outputs: root `SITE-BRIEF.md` and `DESIGN.proposed.md`. Inputs are restricted to `examples/reference/` and `src/config/generated/`; the brief cannot choose arbitrary output paths.

Review the proposal before reconciling it with root `DESIGN.md`, then export and check accepted tokens.

<h2 id="review">Review checklist</h2>

Confirm sources and observations are traceable, three visible transformations survive implementation, no protected text or assets moved, claims have evidence, both locales use TanSail content, keyboard/touch/responsive/reduced-motion behavior works, and the full quality gate passes. Keep unknown customers, metrics, domains, and licenses as unresolved requirements.
