# Blocks and recipes

A block is a normal React component driven by Zod-validated configuration. A recipe is an ordered list of stable block IDs. Together they provide direction without a runtime page builder, global block store, or proprietary content format.

The catalog contains seventeen stable IDs. Logo clouds support grids and compact rails, use cases support rows and filterable catalogs, and testimonials support grids and masonry walls. Testimonial examples carry an explicit `demo` evidence state and visible sample label; switch to `verified` only after replacing every fictional quote and identity with permissioned feedback. Replace example logos, metrics, and prices with verified facts before publishing a real product site.

<h2 id="recipes">Page recipes</h2>

TanSail includes `saas-product`, `ai-tool`, `open-source`, `indie-product`, `knowledge-business`, and `consulting-studio`. Each encodes a maintained narrative order and suggested preset. The preset is guidance, not an override of a visitor's saved choice.

<h2 id="compose">Compose a page</h2>

```tsx
import { LandingBlock } from "#/components/blocks/landing-block";
import { defineLandingBlocks } from "#/config/blocks";

const pageBlocks = defineLandingBlocks([
  {
    kind: "hero",
    id: "launch-hero",
    variant: "product",
    eyebrow: "New release",
    title: "A clear product promise.",
    description: "Explain the outcome in one short paragraph.",
    primaryAction: { label: "Start now", href: "#launch-cta" },
  },
]);

export function LandingPage() {
  return pageBlocks.map((block) => <LandingBlock key={block.id} block={block} />);
}
```

The schema is the type source. Do not maintain parallel interfaces or accept unbounded content objects in block components.

<h2 id="add-block">Extend the system</h2>

First decide whether an existing family only needs new content or a new variant. A new family requires a discriminated schema, inferred exported type, `LandingBlock` dispatch, semantic styles, catalog data, recipe constraints, and tests. Define mobile order, content limits, empty behavior, and reduced-motion behavior.

A new recipe must start with a Hero, end with a CTA, and reference only catalog IDs. Navigate to recipe detail routes with typed params instead of path interpolation.

<h2 id="gallery">Use Gallery</h2>

Open `/gallery/` to filter categories and compare desktop, tablet, and mobile widths across four presets and three theme settings. Gallery is `noindex,nofollow` and excluded from the sitemap. A project may remove it, but should retain equivalent regression coverage.
