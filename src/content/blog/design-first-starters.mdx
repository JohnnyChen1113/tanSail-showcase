# Why a starter should offer direction, not decoration

Many starters are technically complete but visually anonymous. They provide a stack, a dashboard,
and dozens of integrations, then leave the first public page as an afterthought.

TanSail takes a different position: visual direction is part of the foundation, but it should not
be fused to one brand or one page.

## Presets should change more than color

A convincing visual system changes typography, density, geometry, rhythm, and composition
together. Harbor, Horizon, and Nightwatch therefore feel like different products even though the
content contract remains the same.

## Blocks should remain ordinary code

The block library uses typed React components and validated data. There is no page-builder runtime
or proprietary JSON document to migrate later.

## Optional means removable

Content, authentication, billing, and other product capabilities should arrive as modules or
recipes. The default starter stays deployable without secrets and without services a project does
not need.
