# From a clear brief to a coherent landing page

A good generation workflow begins before components are selected. It first identifies the audience,
the promise, the evidence, and the action the page should make easy.

## Start with one primary outcome

The hero should express the result people want, not list every capability. Supporting blocks can
then explain how the product delivers that result.

## Match hierarchy to the story

Use an equal feature grid when capabilities have similar weight. Use bento when one or two ideas
need emphasis. Use split sections when the page benefits from a progressive explanation.

## Close unresolved questions

Pricing and FAQ blocks should reduce decision friction. A final CTA should repeat the next step,
not introduce a new promise.
