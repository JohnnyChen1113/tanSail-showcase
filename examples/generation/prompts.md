# Example generation prompts

## SaaS product

> Use `$build-tansail-site` to create a bright, trustworthy landing site for Northstar, a product intelligence tool for growing software teams. Lead with better decisions, include product capabilities, proof, pricing, FAQ, and a trial CTA. We will deploy to Cloudflare Workers, but the production domain is not decided.

## Open-source project

> Use `$build-tansail-site` to create a technical, high-contrast site for Relay, a small typed event toolkit for TypeScript maintainers. Include a homepage and documentation plan, emphasize explicit event flows, and point the primary CTA to the docs. Deploy it at relay.example.com.

These prompts correspond to the JSON fixtures in this directory. Generated facts such as testimonials, customer logos, usage metrics, and prices must remain placeholders until the user supplies evidence.
